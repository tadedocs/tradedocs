授权与激活

  1. 付款后你会收到一段授权码，安装后打开，把它粘贴进输入框 → 点「激活」即可导出 PDF / Excel。
  2. 授权码离线校验：不联网、不注册、不上传任何数据；激活状态随时可在 设置 → 授权 查看。
  3. 未激活时可免费体验：新建单据、编辑、预览等核心功能全部开放，仅导出 PDF / Excel / Word 需要授权码。
  4. 授权到期后数据不会丢，续费后立即恢复导出功能。
  5. 换电脑 / 换手机：在新设备上再输入一次同一段授权码即可，不绑机器。
安装说明（点开查看）

安卓 / 鸿蒙

  1. 点上面的安卓按钮开始下载（173KB，秒下）。
  2. 下拉通知栏点「外贸制单助手.apk」安装；找不到就去 文件管理 → 下载。
  3. 提示"纯净模式 / 未经安全检测" → 选继续安装；被拦就去 设置 → 系统和更新 → 纯净模式 → 退出。
  4. 提示"禁止安装未知应用" → 设置 → 安全 → 更多安全设置 → 安装外部来源应用 → 允许浏览器。

Windows

  1. 下载后解压整个文件夹（不要只拖出 exe）。
  2. 双击 外贸制单助手.exe，弹出独立窗口，没有地址栏。
  3. 首次可能提示"Windows 已保护你的电脑" → 更多信息 → 仍要运行（未买数字证书，不是病毒）。
  4. 数据在同目录 userdata 里，整个文件夹拷到 U 盘就带走全部单据。

macOS

  1. 解压后把 外贸制单助手.app 拖进「应用程序」。
  2. 首次右键点图标 → 打开 → 再点打开（未签名，需确认一次）。
  3. 它会调用你 Mac 上的 Chrome / Edge 以独立窗口打开；没装就只用 Safari，会带地址栏。
  4. 若提示"已损坏"，终端执行 sudo xattr -dr com.apple.quarantine "/Applications/外贸制单助手.app"。
建议用系统浏览器打开本页。在微信 / QQ 里点开时下载可能被拦：点右上角「···」→「在浏览器打开」，再点下载按钮。
